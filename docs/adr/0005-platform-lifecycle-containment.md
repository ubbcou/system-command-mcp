# Platform lifecycle adapters contain request members

The runtime reports cleanup only for processes contained by its platform Lifecycle Adapter, not every descendant ever created. Windows uses a per-request Job Object implemented through `koffi`: it does not enable a breakaway limit, configures `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE` for final-handle crash cleanup, and uses forced `taskkill /T /F` only as a bounded unconfirmed fallback. Windows has no generic graceful tree-stop request, so termination forces promptly with `gracefulRequested: false`. The fallback retains its observed numeric exit status and output only as diagnostics—local `128` observations are not a portable contract, and its parent/child traversal snapshot can miss reparented work. Node cannot assign a spawned process to a Job race-free: immediate assignment narrows but cannot eliminate the post-spawn/pre-assignment race, in which a detached child can escape; a different pre-existing Job can also reject assignment. Therefore Windows always reports `treeCleaned: false` with `containmentRace: pre-assignment-unverifiable`, even after Job accounting reaches zero. Unix guarantees only the runner-created process group, so a `setsid()` or new process group escapes. `treeCleaned` is true on Unix only after independent bounded confirmation that no contained member remains and is false with stable cleanup diagnostics when containment or confirmation fails. On natural root completion, `reason` remains null; if contained members remain, the adapter still performs containment cleanup and reports its boolean result and truthful `forceUsed`, while `treeCleaned: null` means no cleanup was needed. Windows `.cmd` and `.bat` Platform Wrappers do not provide arbitrary literal arguments: cmd.exe expands and can split `%PATH%`, `!VAR!` depends on delayed expansion, and `&|<>^` is parser syntax that can fail before the wrapper. The runtime rejects those characters plus CR, LF, and NUL for wrappers; accepted wrapper arguments remain a narrowed capability, unlike native executable literal argv.
